# Resource and Latency Budget (XC7Z010-1CLG400C)

Generated by `python/scripts/resource_budget.py`. Block RAM and latency are
analytical bounds derived from `config.py`; LUT/FF/DSP totals come from
`csynth_design` in Phase 3.

## On-chip memory

| Memory | Lives in | Depth | Width | Bits | BRAM36 | LUTs |
|---|---|---|---|---|---|---|
| sample store (PL BRAM, .coe initialised) | block design | 108,000 | 16 | 1,728,000 | 53 | 0 |
| Haar coefficient buffer | ecg_top | 2,048 | 32 | 65,536 | 2 | 0 |
| Haar lifting scratch | ecg_top | 2,048 | 32 | 65,536 | 2 | 0 |
| R-peak index array | ecg_top | 1,502 | 32 | 48,064 | 0 | 751 |
| coder -> packer token FIFO | ecg_top | 128 | 48 | 6,144 | 0 | 96 |
| moving-average window | detect | 18 | 64 | 1,152 | 0 | 18 |

- block design (sample store): **53 / 60 BRAM36**
- ecg_top IP: **4 / 60 BRAM36**
- total: **57 / 60 BRAM36** (95%), 3 blocks spare
- distributed RAM: about **865 / 17600 LUTs** (4.9%)

The sample store dominates and is irreducible: 108,000 x 16 bits stored in
18-bit-wide block RAM wastes two bits per word, which is why it costs more
blocks than a naive bit count suggests. The remaining budget is why the
R-peak array and the token FIFO are bound to distributed RAM and SRL rather
than block RAM.

## Multipliers

The data path is deliberately multiplier-free except for the energy operator:

- IIR bandpass: two shift-based EMAs, no multiply.
- Haar DWT: reversible lifting, adds and a shift only.
- Golomb-Rice and RLE: shifts, compares and a single divide per QRS window.
- TKEO: two products per sample, so a handful of the 80 DSP48s.

## Latency for one 108,000-sample record

| Stage | Cycles (bound) |
|---|---|
| detection pass | 128,000 |
| lossless QRS coding | 74,400 |
| lossy non-QRS coding | 630,400 |
| **total** | **832,800** |

At 100 MHz that is 8.3 ms to compress 300 s of signal, i.e. about **36023x real time**.

Streaming-mode headroom: the core needs about 7.7 cycles per sample against the 277,778 cycles available between
samples at 360 Hz, so a live-input version of the same pipeline would idle
almost all the time.
